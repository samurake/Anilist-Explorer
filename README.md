# AniExplorer

## Overview

You have been hired by a company that builds an app for anime fans. You are responsible for implementing the Home screen on a brand new Android project.

The backend has been developed using GraphQL, and there is a more complex web client that can be used as a reference:

- [AniList Web Client](https://anilist.co/search/anime?format=MOVIE&sort=SCORE_DESC)

## Data

The app uses the AniList GraphQL API. The schema and explorer can be accessed here:

- [GraphQL Schema / Apollo Sandbox](https://studio.apollographql.com/sandbox/explorer?endpoint=https://graphql.anilist.co&explorerURLState=N4IgJg9gxgrgtgUwHYBcQC4TADpIAR4AKAhgOYJ474F6JgCWxluNNAzvSggKoBOANi1Z4UnfhSrCayUv3psAFkKlJiogG4JlNAL7aCYBGyi96AB1EQk2vdVs6QAGhDrip4gCNxbDFmy9cBx0gA)

## UI

The UI should match the provided Figma design as closely as possible, with a pixel-perfect implementation goal:

- [Figma Design](https://www.figma.com/design/cLub3jrsAqCdQzURbFvcsc/Movie-Mobile-App-UI-Design-(Community)?node-id=0-1&p=f&t=ckDwQJvKEEXuYxju-0)

## Technical Requirements

- Use Kotlin and Jetpack Compose
- Follow Android best practices
- Support Android 7+
- Use a modern app architecture such as MVVM, MVI, or a similar pattern
